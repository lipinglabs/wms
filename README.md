# 收发存管理系统（WMS）

面向工程项目部仓库的轻量级物资收发存系统。单文件数据库、零外部依赖、双击即用，适合一个项目部（10～50 人）在局域网内自用。

> 设计取向：**按钮少、页面快、贴合一线流程**。不做通用 ERP，只解决"材料进得来、领得出、退得回、查得清"。

---

## 功能

| 模块 | 说明 |
|---|---|
| 入库 | Excel 粘贴/导入生成入库单，提交后库存增加 |
| 领料申请 | 按工程/队伍/专业列出可用库存，勾选生成申请单，可打印 |
| 出库登记 | 凭领料单出库，支持分批（部分出库），自动算可领量防超领 |
| 退料 | 按领料单退料，库存回补，支持部分退料 |
| 库存 | 按批次查结存，逐物资查看出库/退库流水 |
| 基础档案 | 工程、专业、施工队伍、用户与角色 |
| 系统日志 | 登录与操作记录，仅管理员可见，可筛选、可追溯到人 |
| 报表导出 | 各列表一键导出 Excel（无第三方库，自研 xlsx 生成） |
| 打印 | 单据 PDF 打印（A4 排版） |
| AI 助手 | 右下角悬浮球，自然语言查库存/查去向/问操作（可选，接 Dify） |

### 几个针对现场的设计

- **可申请 = 结存 − 已被其他单据占用**，防止两个人同时把同一批货领走
- **部分出库**：领 100 只出 90 时，剩下 10 会挂在「部分出库」，可在「领用查询 → 部分出库」一键筛出，逐项「放弃领用」了结
- **撤回出库**：数量填错可整单撤回，库存冲回、领料单回到待出库，重新出库即可
- **同批次不合并**：同一物资不同到货日期分行显示，避免账目混淆

## 快速开始

### 方式一：Docker（推荐）

```bash
git clone https://github.com/你的用户名/wms.git
cd wms
docker compose up -d
```

浏览器打开 `http://localhost:18091`，默认账号 `admin / admin888`。

### 方式二：直接跑（已有 Node 22.5+）

```bash
git clone https://github.com/你的用户名/wms.git
cd wms
WMS_PORT=18091 node app/server.js
```

### 方式三：Windows 绿色包

从 [Releases](../../releases) 下载 `wms-win-x64.zip`，解压后双击 `启动系统.bat`，无需安装任何东西。

## 首次使用

1. 用 `admin / admin888` 登录，**立即修改密码**（右上角 → 修改密码）
2. 建基础档案：工程 → 专业 → 施工队伍
3. 建用户：给仓管员、领料员分配角色和工程范围
4. 录入期初库存：入库登记 → 粘贴 Excel 或下载模板填写
5. 开始日常流转

## 权限

| 角色 | 能做什么 |
|---|---|
| 管理员 | 全部功能（含系统日志） |
| 二级管理员 | 收发存全部 + 撤回已提交单据 + 放弃领用；无基础档案与授权 |
| 仓管员 | 入库/出库/退料/库存/查询，不能建领料申请 |
| 领料员 | 提领料申请、查库存、放弃领用；不能出库 |
| 只读 | 仅查看 |

## 配置

全部通过环境变量，都有默认值，**不配也能跑**：

| 变量 | 默认 | 说明 |
|---|---|---|
| `WMS_PORT` | 18091 | 监听端口 |
| `WMS_HOST` | 0.0.0.0 | 监听地址 |
| `WMS_DATA_DIR` | `app/data` | 数据目录（放数据库和备份） |
| `WMS_DIFY_URL` | — | Dify 地址，不配则 AI 助手关闭 |
| `WMS_DIFY_KEY` | — | Dify 应用密钥 |
| `WMS_BACKUP_REMOTE` | — | 异地备份目标（如 `user@host`），不配则只存本地 |

## 数据与备份

- 数据库是单个 SQLite 文件：`data/wms.db`（WAL 模式）
- **库存余额全部由流水汇总得出**，没有单独的余额字段，不存在对不上的可能
- 每天 00:00 自动整机备份（数据库快照 + 代码打包），本地保留 30 份
- 工作台会显示「最近备份时间」，超过 36 小时未备份变红提醒

手动备份：`node app/backup-now.js`

## 目录结构

```
app/
  server.js          路由分发 + 静态文件 + 会话
  lib/
    db.js            建表、迁移、库存汇总 SQL
    routes.js        全部页面与业务逻辑
    auth.js          登录、会话、角色权限
    audit.js         系统日志：登录/操作记账与历史补录
    ui.js            服务端渲染组件（表格、表单）
    xlsx.js          Excel 生成（无第三方依赖）
    printpdf.js      单据 PDF 打印
    ai.js            AI 助手（意图识别 + 数据组装）
    backup.js        每日备份与轮转
  public/            前端样式与少量交互脚本
tests/               端到端测试（每个套件独立数据库）
```

**技术栈**：Node.js 22+（`node:http` / `node:sqlite` / `node:crypto`），服务端渲染，无前端框架、无 npm 依赖、无构建步骤。

## 常见问题

**同事访问不了？**
服务端是 `0.0.0.0`，确认对方和你在同一局域网，并放行防火墙端口（Windows：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则）。

**端口被占用？**
启动时设 `WMS_PORT=18092`（绿色包改 `启动系统.bat` 里的数字）。

**手机能用吗？**
能，同一局域网直接访问 IP。表格窄屏下会横向滚动。

**要装数据库吗？**
不用，SQLite 是 Node 内置模块，数据就是一个文件，拷走即可。
